# 데이터 전처리 및 타겟 정의 명세서

## 1. 데이터 소스 및 재현성 확인
- **원본 데이터**: NHANES 2009-2010 (ARQ_F, PAQ_F, BMX_F, SLQ_F, SMQ_F, DEMO_F)
- **재현성 확인 결과**:
  - Arthritis 설문 응답자(ARQ010): 5,103명
  - 최종 전처리 샘플 수: 4,734명 (결측치 제거 후)
  - 타겟 분포: 음성(0) 80.63% / 양성(1) 19.37%

## 2. 타겟 변수 정의 및 검증
### 양성군 (Target = 1)
- **정의**: 지난 30일 동안 6주 이상 지속된 허리 통증 경험자
- **추출 규칙**: `ARQ020D == 4`
- **검증**: ARQ020D 문항은 "지난 30일 동안 6주 이상 지속된 허리 통증이 있었습니까?"라는 질문에 대한 응답임.

### 음성군 (Target = 0)
- **정의**: 허리 통증이 없거나, Arthritis 설문에서 통증 증상이 없다고 응답한 자
- **추출 규칙**: 
  - `ARQ010 == 2` (관절염 증상 없음) -> 허리 통증 없음으로 간주
  - `ARQ010 == 1` 이지만 `ARQ020D != 4` (다른 부위 통증은 있으나 허리는 없음)
- **해석**: 본 모델에서 음성군은 "장기적인 허리 통증이 없는 상태"를 의미함.

### 보조 타겟 (ARQ024D)
- **내용**: 3개월 이상 지속된 허리 통증 여부
- **결정**: 현재는 6주 이상(ARQ020D)을 기본 타겟으로 사용하되, 향후 만성도를 높인 모델이 필요할 경우 ARQ024D를 활용한 하위 분석 가능.
