| 핵심 메시지 | 설명 |
|---|---|
| 모델을 많이 쓰는 것이 목적이 아니다 | baseline → 비선형 비교 → 득점 기반 확장 → 확률 보정 순서로 설명 가능한 구조를 만드는 것이 목적이다. |
| Logistic Regression은 기준선이다 | 가장 해석 가능한 baseline으로, 이후 모델의 개선 여부를 비교하는 기준이다. |

| Logistic Regression | 해석 가능한 기준 모델 | “가장 먼저 세운 해석 가능한 기준 모델로, 이후 모델들이 실제로 개선되는지 비교하는 기준선입니다.” | 확정 |
| Random Forest | 비선형 패턴과 변수 상호작용 비교 | “Random Forest는 랭킹과 경기 맥락이 단순 선형이 아닐 수 있다는 점을 확인하기 위한 비교 모델입니다.” | 확정 |

| K-Means / 팀 유형 군집화 | 참가국 유형 설명 보조 | “군집화는 예측 모델 자체보다 참가국 유형을 설명하는 발표 보조 분석으로 활용할 수 있습니다.” | 확인필요 |

## 4. 발표에서 강조할 메시지

1. 우리 프로젝트는 단순히 복잡한 모델을 많이 붙이는 방식이 아니라, 기준선을 세우고 비교·검증하는 순서로 접근한다.
2. Logistic Regression과 Random Forest는 현재 baseline과 비교 모델로 설명한다.
3. Poisson Regression은 축구 득점 구조와 연결되는 확장 아이디어로 두되, 현재 주력 구현으로 단정하지 않는다.
4. XGBoost/LightGBM은 성능 고도화 후보지만, 발표 전 검증 시간이 부족하면 선택 확장으로 남기는 것이 안전하다.
5. 우승 확률과 토너먼트 시뮬레이션은 확률값을 사용하므로, calibration은 발표 방어에 중요하다.

## 7. 예상 질문과 답변

### Q1. “왜 Logistic Regression을 사용했나요?”

A. 가장 해석 가능한 기준 모델이기 때문입니다. 복잡한 모델을 쓰기 전에 단순하고 재현 가능한 baseline을 세워야 이후 모델이 실제로 개선되는지 판단할 수 있습니다.

### Q2. “Random Forest는 어떤 의미가 있나요?”

A. 축구 경기 결과는 랭킹 차이, 중립 경기 여부, 팀 특성 등이 단순 선형으로만 설명되지 않을 수 있습니다. Random Forest는 이런 비선형 패턴과 변수 상호작용을 비교하기 위한 모델입니다.

### Q3. “Poisson Regression은 왜 언급하나요?”

A. 축구는 득점 수가 낮은 경기라 득점 예측 기반 접근이 자주 사용됩니다. Poisson 계열 접근은 득점을 예측한 뒤 승/무/패로 변환하는 방식이라 축구 도메인 설명력이 있습니다. 다만 현재 구현 여부는 팀 결정이 필요합니다.

### Q4. “XGBoost나 LightGBM을 쓰면 더 좋은가요?”

A. 성능 향상 가능성은 있지만 튜닝과 검증 부담이 큽니다. 실행 결과 없이 성능 우위를 단정하면 위험하므로, 발표에서는 고도화 후보 또는 선택 확장 모델로 표현하는 것이 안전합니다.

### Q5. “Calibration은 왜 중요한가요?”

A. 우승 확률과 토너먼트 시뮬레이션은 모델의 확률값을 입력으로 사용합니다. 따라서 단순히 맞췄는지보다 예측 확률이 얼마나 믿을 만한지 확인해야 하며, calibration은 그 품질을 검증하는 단계입니다.
