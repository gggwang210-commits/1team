# 모델 고도화 및 실험 리포트

본 리포트는 허리 통증 위험 예측 모델의 성능을 최적화하기 위해 수행한 임계값(Threshold) 비교 및 불균형 데이터 대응 실험 결과를 정리한 것입니다.

## 1. 임계값(Threshold) 비교 실험
로지스틱 회귀 모델(Balanced)을 대상으로 임계값 변화에 따른 Precision, Recall, F1-Score의 변화를 분석했습니다.

| Threshold | Precision | Recall | F1-Score | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 0.30 | 0.198 | **0.962** | 0.329 | 극단적 스크리닝 |
| 0.40 | 0.219 | 0.776 | 0.341 | |
| **0.50** | 0.256 | 0.563 | **0.352** | **최적 균형점** |
| 0.60 | 0.317 | 0.311 | 0.314 | |

- **결과 해석**: 임계값이 낮아질수록 재현율(Recall)은 급격히 상승하지만 정밀도(Precision)가 하락합니다. 본 프로젝트의 목적인 "위험군 스크리닝"을 위해서는 F1-Score가 가장 높고 적절한 재현율을 확보한 **0.50**을 기본 임계값으로 유지하되, 필요에 따라 0.40까지 낮추어 보수적인 스크리닝을 수행할 수 있습니다.

## 2. 불균형 대응 및 모델 비교
| 모델 설정 | Recall | F1-Score | ROC-AUC |
| :--- | :--- | :--- | :--- |
| Logistic Regression (Default) | 0.016 | 0.032 | 0.619 |
| **Logistic Regression (Balanced)** | **0.563** | **0.352** | **0.619** |
| Random Forest (Balanced) | 0.268 | 0.297 | 0.583 |

- **결론**: `class_weight='balanced'`를 적용한 로지스틱 회귀 모델이 소수 클래스(통증군)에 대한 탐지력(Recall)을 비약적으로 향상시켰습니다. ROC-AUC 수치(0.619)를 고려할 때, 선형적 관계를 가진 변수들이 모델 분류에 주요하게 기여하고 있음을 시사합니다.

## 3. 변수 조합 실험 (요약)
- **BMI vs 허리둘레**: 두 변수는 강한 상관관계를 보이나, Permutation Importance 분석 결과 **허리둘레(Waist)**가 모델 성능에 더 기여하는 것으로 나타났습니다.
- **흡연 변수**: 단순 흡연 여부(`smoke_100`)만으로도 유의미한 관련 신호가 관찰되었습니다.
