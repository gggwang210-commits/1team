# 모델링 결과 보고서: 허리 통증 위험 예측 모델

## 1. 모델 개요 및 학습 설정
- **데이터셋**: NHANES 2009-2010 (N=4,734)
- **학습/테스트 분할**: 80% / 20% (Stratified)
- **평가 지표**: Accuracy, Precision, Recall, F1, ROC-AUC
- **불균형 대응**: `class_weight='balanced'` 적용 (양성 비율 약 19.4%)

## 2. 모델 성능 비교
| 모델 | Accuracy | Precision | Recall | F1 | ROC-AUC |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Baseline (다수결)** | 0.807 | 0.000 | 0.000 | 0.000 | 0.500 |
| **Logistic Regression** | 0.600 | 0.256 | **0.563** | 0.352 | **0.619** |
| **Random Forest** | 0.755 | 0.333 | 0.268 | 0.297 | 0.583 |

- **해석**: 로지스틱 회귀 모델이 가장 높은 **재현율(Recall, 0.563)**과 **ROC-AUC(0.619)**를 기록했습니다. 본 프로젝트의 목적이 "위험군을 놓치지 않는 것"에 있으므로, 로지스틱 회귀를 1차 핵심 모델로 선정합니다.

## 3. 변수 중요도 분석 (Permutation Importance)
테스트 데이터셋에 대해 모델의 예측 성능에 미치는 영향력을 분석한 결과입니다.

| 순위 | 변수 | 중요도 (정확도 감소분) | 해석 (관련 신호) |
| :--- | :--- | :--- | :--- |
| 1 | **Waist (허리둘레)** | 0.0239 | 허리둘레가 증가할수록 통증 위험 신호 강화 |
| 2 | **Smoke_100 (흡연)** | 0.0222 | 흡연 경험이 통증 위험과 연관됨 |
| 3 | **Sleep Hours (수면)** | 0.0186 | 수면 시간이 부족할수록 통증 위험 신호 관찰 |
| 4 | **Gender (성별)** | 0.0084 | 성별에 따른 위험도 차이 존재 |
| 5 | **BMI** | 0.0045 | 체질량 지수와 통증 간의 상관성 |

- **주의**: 위 지표는 "인과관계"가 아닌 통계적 "관련 신호"를 의미합니다. 예를 들어, 허리둘레가 넓은 사람이 통증을 더 많이 경험하는 경향이 있다는 것을 시사합니다.

## 4. 결론 및 한계
- **성과**: 기준선 모델 대비 위험군 탐지 능력을 확보했으며, 허리둘레와 흡연, 수면이 주요 위험 신호임을 확인했습니다.
- **한계**: 
  - 단면 설문 데이터이므로 인과 추론은 불가능합니다.
  - 의료 진단 도구가 아닌 교육용 분석 모델입니다.
  - 미국 데이터 기반이므로 한국인 대상 적용 시 국민건강영양조사 데이터로의 확장이 필요합니다.
